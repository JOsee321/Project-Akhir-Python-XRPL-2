# 🎮 Project Akhir Python - X RPL 2

Proyek ini dibuat untuk memenuhi tugas **Project Akhir Python** pada semester ini untuk kelas **X RPL 2**. Aplikasi ini merupakan implementasi dari konsep dasar pemrograman yang telah dipelajari di kelas Rekayasa Perangkat Lunak.

## 📝 Identitas Project
*   **Mata Pelajaran**: Pemrograman Dasar (Python)[cite: 1]
*   **Kelas**: X RPL 2
*   **Judul Project**: Game Gunting Batu Kertas
*   **Pengembang**: Rafi Wildan

## 📋 Spesifikasi Tugas (Kriteria Penilaian)
Sesuai dengan instruksi praktikum, program ini telah memenuhi syarat minimal sebagai berikut:
1.  **Minimal 50 Baris Kode**: Menggunakan penulisan yang rapi dan terstruktur
2.  **Percabangan (If-Else)**: Digunakan untuk logika penentu pemenang dan menu navigasi
3.  **Perulangan (While Loop)**: Digunakan agar permainan dapat berjalan terus menerus (Looping)
4.  **Function**: Memisahkan logika permainan ke dalam fungsi `tentukan_pemenang` dan `main`
5.  **Tipe Data (Statis & Dinamis)**:
    *   **Statis**: Penggunaan String untuk nama dan Boolean untuk status game
    *   **Dinamis**: Penggunaan List `pilihan_game` untuk menampung data emoji

## 🛠️ Fitur Aplikasi
*   **Input Data**: Menerima input nama pelanggan/pemain
*   **Konversi Tipe Data**: Melakukan casting `int()` pada input string untuk pengolahan data
*   **Visual Emoji**: Menggunakan visual 🪨, 📜, dan ✂️ agar tampilan lebih interaktif
*   **Sistem Skor**: Menghitung total kemenangan pemain secara otomatis
*   **Struk Akhir**: Menampilkan ringkasan hasil permainan saat user memilih keluar
