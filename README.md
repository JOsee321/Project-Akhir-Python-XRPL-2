# 🎮 Project Akhir Python - X RPL 2

Proyek ini dibuat untuk memenuhi tugas **Project Akhir Python** pada semester ini untuk kelas **X RPL 2**. Aplikasi ini merupakan implementasi dari konsep dasar pemrograman yang telah dipelajari di kelas Rekayasa Perangkat Lunak[cite: 1].

## 📝 Identitas Project
*   **Mata Pelajaran**: Pemrograman Dasar (Python)[cite: 1]
*   **Kelas**: X RPL 2[cite: 1]
*   **Judul Project**: Game Gunting Batu Kertas (Emoji Edition)[cite: 1]
*   **Pengembang**: Jose (Rafi Wildan)[cite: 1]

## 📋 Spesifikasi Tugas (Kriteria Penilaian)
Sesuai dengan instruksi praktikum, program ini telah memenuhi syarat minimal sebagai berikut:
1.  **Minimal 50 Baris Kode**: Menggunakan penulisan yang rapi dan terstruktur[cite: 1].
2.  **Percabangan (If-Else)**: Digunakan untuk logika penentu pemenang dan menu navigasi[cite: 1].
3.  **Perulangan (While Loop)**: Digunakan agar permainan dapat berjalan terus menerus (Looping)[cite: 1].
4.  **Function**: Memisahkan logika permainan ke dalam fungsi `tentukan_pemenang` dan `main`[cite: 1].
5.  **Tipe Data (Statis & Dinamis)**:
    *   **Statis**: Penggunaan String untuk nama dan Boolean untuk status game[cite: 1].
    *   **Dinamis**: Penggunaan List `pilihan_game` untuk menampung data emoji[cite: 1].

## 🛠️ Fitur Aplikasi
*   **Input Data**: Menerima input nama pelanggan/pemain[cite: 1].
*   **Konversi Tipe Data**: Melakukan casting `int()` pada input string untuk pengolahan data[cite: 1].
*   **Visual Emoji**: Menggunakan visual 🪨, 📜, dan ✂️ agar tampilan lebih interaktif[cite: 1].
*   **Sistem Skor**: Menghitung total kemenangan pemain secara otomatis[cite: 1].
*   **Struk Akhir**: Menampilkan ringkasan hasil permainan saat user memilih keluar[cite: 1].
